# NwpuThesis Embedded Template

This is a trimmed template bundle derived from `1195343015/nwputhesis` for the `doc2latex for nwpuers` branch.

Kept:

- `nwputhesis.cls`
- required `infra/*.def`
- required cover, backcover, logo, and school-name assets
- graduate authorization statement placeholder PDF
- minimal undergraduate and graduate content skeletons

Removed:

- GitHub workflow files
- VS Code settings
- QQ group image
- demo screenshot
- verbose sample chapters
- font submodule
